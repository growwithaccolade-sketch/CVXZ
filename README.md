# CV Bible

Free no-signup resume creation. Homepage built with React, Vite, and Motion. Existing editor at `/builder.html` with ten layouts, local autosave, cover-letter drafting, a basic keyword comparison and print PDF / Word-compatible .doc exports.

Run `npm install && npm run build` to validate.

All CV data is browser-local. Writing assistance is rule based; job matching is a simple vocabulary comparison, not a certified ATS score. Word files use HTML-based `.doc`, not native `.docx`.

Administration of this static project is via GitHub access; a separate admin dashboard is not implemented.
